    What you would be starting.

    • What exists today

      Catholic Leaders in Action is one group in San Francisco, run by volunteers, formed in partnership with the Archdiocese of San Francisco.

      Everything it has run is on the events page

    • What a hub would be

      A group like this one, in your city, run by you, with the same shape: an evening a month, a speaker, a panel, and a room people can actually talk in.

    • What we can offer

      Honestly, right now: the format, what we have learned running it, and an introduction. Not funding, not staff, not a licence. If more than that becomes possible, it will be because enough people filled in this form.
